# 隐私与安全说明

## 数据分类

| 数据 | 保存位置 | 是否联网 |
| --- | --- | --- |
| Base URL、模型名称 | HarmonyOS Preferences | 测试或请求模型时使用 |
| API Key | HarmonyOS Asset Store | 作为用户选择的模型 API 认证信息 |
| 内置法律索引 | App 只读资源 | 否 |
| 对话与案件信息 | 当前 App 会话 | 用户提交咨询时发送给模型服务商 |
| TXT/MD/DOCX 附件 | 本机读取和临时处理 | 用户提交咨询时发送必要文本 |

## API Key

- 仓库中不包含真实 API Key。
- App 使用 Asset Store Kit 保存 API Key。
- 资产设置为设备首次解锁后可访问，并禁止跨设备同步。
- Base URL 必须使用 HTTPS。
- 用户应只填写可信模型服务商提供的地址，并遵守该服务商的隐私政策。

## 附件

- 通过系统 DocumentViewPicker 由用户主动选择。
- App 不申请笼统的全盘文件权限。
- 单个源文件最大 8 MB。
- DOCX 解压后的总大小上限为 20 MB。
- 送入模型的提取文本最多 16000 个字符。
- DOCX 临时内容放在应用缓存目录，不作为知识库长期保存。

附件内容会被标记为待分析数据，不能覆盖系统指令。尽管如此，用户仍不应上传无权
处理的个人信息、商业秘密或与咨询无关的敏感材料。

## 本地知识库

内置索引是在开发阶段机械生成的只读资源。它不会自动更新，也没有完成：

- 全面法律效力审查；
- 失效/废止法规清理；
- 重复文件消除；
- 历史版本合并；
- 图片和扫描件 OCR。

回答页展示候选资料的来源、条文和状态，使用者仍需通过政府或司法机关官方渠道核对。

## 模型输出

模型可能产生错误、遗漏或过时结论。本项目通过本地候选条文和引用 ID 校验降低幻觉，
但不能消除风险。应用不应被用于替代律师意见、仲裁裁决、行政决定或司法判决。

## 开源仓库安全

提交前应检查并排除：

- `.env`、`users.json` 和反馈数据；
- DevEco `local.properties`、`.idea/`、`.hvigor/`；
- `.p12`、`.p7b`、`.cer`、私钥和签名口令；
- HAP、构建目录、模拟器截图和用户附件；
- 真实请求日志或含个人信息的测试数据。

如果发现仓库中存在有效密钥，不要只删除文件：应立即在对应服务商处撤销密钥，再清理
Git 历史并发布安全说明。
